### 遇到的问题及解决
1. **Gradle 锁文件冲突**：GRADLE_USER_HOME（D:\Android\.gradle）中有大量 .lock 文件"拒绝访问"
   - 原因：两个 Gradle 8.5 daemon 进程（PID 3828 和 25280，后者来自 Android Studio）锁住了共享缓存
   - `./gradlew --stop` 只停 8.8 daemon，无法停 8.5 的
   - 解决：`taskkill /F /PID 3828` 和 `taskkill /F /PID 25280` 终止 8.5 daemon，再 `find ... -name "*.lock" -delete` 清除所有锁文件
2. **阿里云镜像缺失**：`~/.gradle/init.gradle` 不存在，已创建并同步到 `D:/Android/.gradle/init.gradle`（GRADLE_USER_HOME 实际位置）
   - 重定向 Maven Central / Google / JCenter / Gradle Plugin Portal 到阿里云镜像
